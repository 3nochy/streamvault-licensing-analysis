# StreamVault Licensing Analysis

This project compares franchise candidates with standalone proxies from the supplied TMDb movie ID list. Historical theatrical revenue is used as a ranking signal; it is not a measure of streaming value, licensing cost, or profit.

## Setup

Use Python 3.12 or newer. Create and activate a virtual environment, then install the pinned dependencies:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set `TMDB_API_KEY` to a personal TMDb API key. Never commit `.env`. Shared paths and request settings are in `pipeline/config.py`. The first extraction needs internet access and makes two TMDb requests for each first-occurrence valid ID; successful responses are cached under `data/raw/` for later offline transformation. Use `python -m pipeline.extract --refresh` for a quarterly refresh so cached responses do not make the analysis stale.

## Run the workflow

Run commands from the repository root:

```bash
python -m pipeline.extract  # Add --refresh for a live refresh
python -m pipeline.transform
python -m pipeline.run_notebooks
python -m unittest discover -s tests
```

The notebook runner executes source diagnosis first and licensing analysis second, updates both notebooks with their outputs, and exports memo evidence tables to `out/`. If notebook execution fails, the run is incomplete; fix the error and rerun the full workflow before using the results. Earlier notebooks may already have saved updated outputs.

The raw and processed datasets are intentionally excluded from Git and are regenerated by extraction and transformation.

The manual TMDb API smoke check is separate from the main workflow. Run it from the repository root with:

```bash
python scripts/check_tmdb_client.py
```

This script makes live TMDb API requests and requires a valid `TMDB_API_KEY` in the environment.

## Outputs and limitations

The client memo is in `docs/client_memo.md`, and the full candidate-list diagnosis is in `docs/data_findings.md`. Extraction and transformation audits are written to `data/processed/`. Licensing categories are proxies based on TMDb collection membership. The $14 million budget cannot be assessed for affordability without actual quotes and rights terms. See `docs/data_contract.md`, the ADRs, and `docs/findings.md` for pipeline rules and investigation notes.

The improvement beyond the original brief—automated reconciliation and validation—is described in `docs/improvement.md`.
